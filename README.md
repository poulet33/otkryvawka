# Макеты «Открывашки» · Школа Ямолод

Статичный сайт для показа макетов. Сборки нет: открывается как обычные файлы, подходит для GitHub Pages, Netlify, Vercel и любого хостинга.

## Страницы

- `index.html` — главная со ссылками на все макеты
- `cover.html` — обложка блокнота А5 (передняя и задняя)
- `plaque.html` — плакетка гранта А3, чёрная и белая версии
- `bag-polyethylene.html` — полиэтиленовый пакет 30×35×6 см (арт. 19017)
- `bag-paper.html` — бумажный пакет 25×35×8 см

Шрифты Masiva и логотип лежат рядом с страницами.
Страницы пакетов подгружают шрифты Unbounded и Golos Text с Google Fonts, поэтому им нужен интернет.

## Запуск на GitHub Pages

Settings → Pages → Source: ветка `main`, папка `/ (root)`.
